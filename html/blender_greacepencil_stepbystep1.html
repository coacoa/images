Blender Grease Pencil 学習ステップ（2.7 / 2.8+ 共通）

1. 基本操作の理解

  • Grease Pencil の追加
    2.7: N パネル → Grease Pencil
    2.8+: Shift + A → Grease Pencil → Blank / Stroke / Monkey
  • 描画モード切替
    2.7: D + LMB（デフォルト）
    2.8+: Ctrl + Tab → Draw
  • 基本ショートカット
    描画: D + LMB（2.7） / Draw モード
    消しゴム: E
    ストローク選択: L / A
    移動: G / 回転: R / スケール: S

2. ストローク編集の基礎

  • Edit モード
    2.7: Tab（Grease Pencil → Edit）
    2.8+: Ctrl + Tab → Edit
  • ポイント編集
    選択: B / C
    スムーズ: Shift + S
    太さ変更: N → Stroke → Thickness

3. レイヤー管理

  • レイヤー追加: +
  • レイヤーのロック・表示切替
  • アニメ用に「背景」「キャラ」「線画」など分離

4. マテリアル（色・線幅）

  • 色設定: Properties → Material
  • 線幅: Stroke Thickness
  • 塗りつぶし: Fill

5. アニメーションの基礎

  • キーフレーム追加: I
  • フレーム移動: 左右矢印キー
  • Onion Skin: Viewport Display → Onion Skin

6. 実践ステップ（順番）

  1. 線を描く（Draw）
  2. ポイント編集（Edit）
  3. レイヤー分け
  4. 色・線幅設定
  5. 簡単な動き（2〜3フレーム）
  6. 短いループアニメ（歩き・揺れ）

7. 2.7 系で注意する点

  • 描画は D + LMB が基本
  • Grease Pencil は「補助線」扱い → 2.8 以降のような完全なオブジェクトではない
  • アニメ機能は簡易的（本格的には 2.8+ 推奨）
