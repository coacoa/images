Grease Pencil 学習ステップ（2.7 → 4.4 / 5.1 対応）

1. 基本操作

  • Grease Pencil の追加
    2.7: N パネル → Grease Pencil
    4.4/5.1: Shift + A → Grease Pencil → Blank / Stroke / Monkey
  • 描画モード切替
    2.7: D + LMB
    4.4/5.1: Ctrl + Tab → Draw
  • 消しゴム
    2.7: E
    4.4/5.1: E（同じ）

2. ストローク編集

  • Edit モード
    2.7: Tab
    4.4/5.1: Ctrl + Tab → Edit
  • ポイント選択
    2.7: B / C
    4.4/5.1: B / C（同じ）
  • 移動・回転・スケール
    共通: G / R / S

3. レイヤー管理

  • レイヤー追加: +
  • ロック・表示切替: 共通 UI

4. マテリアル（色・線幅）

  • 色設定: Properties → Material
  • 線幅: Stroke Thickness
  • 塗りつぶし: Fill

5. アニメーション

  • キーフレーム追加: I
  • フレーム移動: ← →
  • Onion Skin: Viewport Display → Onion Skin

6. 実践ステップ

  1. 線を描く（Draw）
  2. ポイント編集（Edit）
  3. レイヤー分け
  4. 色・線幅設定
  5. 簡単な動き（2〜3フレーム）
  6. 短いループアニメ（歩き・揺れ）
