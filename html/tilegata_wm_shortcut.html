Tiling WM & Omarchy Keybindings

Omarchy, Hyprland, Niri, Sway, i3, dwm のデフォルトショートカット一覧

Omarchy / Hyprland

OmarchyはHyprlandをベースにしており、通常のHyprlandデフォルト設定をさらに洗練させています。MODキーは通常 SUPER です。

操作 デフォルトショートカット
ターミナル起動SUPER + Q または SUPER + ENTER
アプリランチャー (Fuzzel/Rofi)SUPER + SPACE または ALT + F1
ウィンドウを閉じるSUPER + C または SUPER + Q
フォーカス移動SUPER + H/J/K/L または 矢印キー
ウィンドウ移動SUPER + SHIFT + H/J/K/L
ワークスペース移動SUPER + 1〜9
ウィンドウをワークスペースへ送るSUPER + SHIFT + 1〜9
フロート/タイル切替SUPER + F (または独自キー)
リロード / 終了SUPER + SHIFT + R / SUPER + M (Exit)

Niri (スクロール型 Wayland コンポジター)

無限に広がる水平方向のスクロールレイアウトが特徴です。MODキーは SUPER。

操作 デフォルトショートカット
ターミナル起動SUPER + T
アプリランチャー (App Launcher)SUPER + D
ウィンドウを閉じるSUPER + Q
フォーカス移動 (左右カラム)SUPER + Left / Right (または H / L)
カラム内ウィンドウ移動SUPER + Up / Down (または K / J)
ウィンドウの列移動SUPER + SHIFT + Left / Right
フルスクリーン切替SUPER + F
セッション終了 (Quit)SUPER + SHIFT + E

Sway / i3 (i3互換環境)

X11 (i3) および Wayland (Sway) で共通の極めて似たキーバインドを持ちます。MODキーは SUPER (Mod4) または ALT (i3のデフォルト一部設定)。

操作 デフォルトショートカット
ターミナル起動SUPER + ENTER
アプリランチャー (dmenu / rofi)SUPER + D
ウィンドウを閉じるSUPER + SHIFT + Q
フォーカス移動SUPER + J/K/L/; (または矢印)
ウィンドウ移動SUPER + SHIFT + J/K/L/;
分割方向切替 (水平/垂直)SUPER + H / SUPER + V
フルスクリーン切替SUPER + F
ワークスペース移動SUPER + 1〜9
設定リロードSUPER + SHIFT + C
Sway/i3 終了SUPER + SHIFT + E

dwm (Dynamic Window Manager - X11)

C言語で書かれた軽量WM。MODキーはデフォルトで ALT (Mod1) です。

操作 デフォルトショートカット
ターミナル起動 (st等)ALT + SHIFT + ENTER
アプリランチャー (dmenu)ALT + P
ウィンドウを閉じるALT + SHIFT + C
フォーカスの順次切替ALT + J / ALT + K
マスターウィンドウへ昇格ALT + ENTER
マスター領域の拡大/縮小ALT + H / ALT + L
レイアウト切替 (タイル/モンクル等)ALT + T / ALT + M 等
ワークスペース (Tag) 移動ALT + 1〜9
dwmの終了 (Quit)ALT + SHIFT + Q
