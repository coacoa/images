NixOS + Samba NAS セットアップ手順メモ

目的：NixOS 上で 32GB (mmc) ディスクを NAS として共有する

1. ディスク構成の確認

lsblk

例：

sda        128G  → NixOS 本体
mmcblk0     32G  → NAS 用データディスク

2. NAS 用ディスクをフォーマット

※ データは消えるので注意

sudo mkfs.ext4 /dev/mmcblk0p1
sudo e2label /dev/mmcblk0p1 NAS32G
UUID 確認： 
lsblk -f /dev/mmcblk0p1

3. マウント設定

sudo mkdir -p /mnt/nas
# /etc/nixos/configuration.nix
fileSystems."/mnt/nas" = {
  device = "/dev/disk/by-uuid/XXXX-XXXX";
  fsType = "ext4";
  options = [ "noatime" "nodiratime" ];
};
sudo nixos-rebuild switch

4. Samba を有効化

# /etc/nixos/configuration.nix
services.samba = {
  enable = true;
  shares.nas = {
    path = "/mnt/nas";
    browseable = "yes";
    writable = "yes";
    guestOk = "no";
  };
};

5. ファイアウォール設定（重要）

これを忘れると外部から接続できない

# /etc/nixos/configuration.nix
networking.firewall = {
  enable = true;
  allowedTCPPorts = [ 445 139 ];
  allowedUDPPorts = [ 137 138 ];
};
sudo nixos-rebuild switch

6. Samba サービス確認

systemctl status samba-smbd

active (running) なら OK

7. Samba ユーザー作成（超重要）

Linux ユーザーと Samba ユーザーは別

sudo smbpasswd -a hoge
sudo smbpasswd -e hoge
確認： 
pdbedit -L

8. ディレクトリ権限設定

sudo chown -R hoge:users /mnt/nas
sudo chmod -R 775 /mnt/nas

9. 接続テスト

Linux

smb://192.168.1.111/nas

Windows

\\192.168.1.111\nas

ユーザー名：hoge
パスワード：smbpasswd で設定したもの

10. 完成 🎉

  • NixOS 本体：128GB SSD
  • NAS データ：32GB mmc
  • Samba 認証：有効
