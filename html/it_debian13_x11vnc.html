Debian 13 x11vnc リモート接続メモ

目的: 本体 (ASUS T103HAF) の画面を、パスワード入力なしで自動起動し、他PCからVNCでそのまま操作する。

1. x11vnc のインストールと準備

まず必要なソフトを入れ、接続用のパスワードを設定します。

sudo apt update
sudo apt install x11vnc
x11vnc -storepasswd

※パスワードは ~/.vnc/passwd に保存されます。

2. Systemd による自動起動設定

OS起動時（自動ログイン後）にバックグラウンドでVNCを待機させます。

sudo nano /etc/systemd/system/x11vnc.service

以下の内容を貼り付け（hoge は自分のユーザー名に変更）：

[Unit]
Description=Start x11vnc at startup.
After=multi-user.target

[Service]
Type=simple
ExecStart=/usr/bin/x11vnc -auth guess -forever -loop -noxdamage -repeat -rfbauth /home/hoge/.vnc/passwd -display :0
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target

3. サービスの有効化

設定を反映させ、次回から自動で立ち上がるようにします。

sudo systemctl daemon-reload
sudo systemctl enable x11vnc
sudo systemctl start x11vnc

4. 接続クライアントの設定

他PCから以下の情報で接続します：

  • プロトコル: VNC
  • アドレス: 192.168.1.5:5900 (または現在のIP)
  • パスワード: 手順1で決めたもの
Atom PC 快適化のヒント:
T103HAFは非力なため、VNCクライアント側の設定で 「Low Color (256色)」 や 「Encoding: Tight」 を選ぶと動作が軽くなります。

✅ これで「本体自動ログイン」＋「リモート画面共有」の環境が完成です！
