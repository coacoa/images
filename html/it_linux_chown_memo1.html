Linux / NixOS でよく落ちる罠：chown とグループ

現象：
chown: invalid group: hoge:hoge

Linux の chown は 

chown ユーザ:グループ ファイル

という形式。
つまり 「ユーザ名」と「グループ名」は別物。

NixOS では多くの場合： 

ユーザ: hoge
グループ: users

👉 hoge:hoge というグループは存在しない。

ユーザとグループを確認：

id hoge

例：

uid=1000(hoge) gid=100(users) groups=100(users)
  
sudo chown hoge:users /etc/x11vnc.pass
sudo chmod 600 /etc/x11vnc.pass
  • Ubuntu系は「ユーザ名＝同名グループ」が多い
  • NixOS は「users」グループ文化
  • systemd / サービス実行ユーザが絡む

👉 知識が線でつながってないと「理由不明エラー」に見える

Linux では：
「ユーザ ≠ グループ」
「NixOS の基本グループは users」
