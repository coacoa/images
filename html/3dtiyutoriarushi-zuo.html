    GitHub Pages で本番化する手順

    この試作を「自分のモデルの教材」に育てる流れ。

    1. Blender でモデルを作る — 部品ごとにオブジェクトを分け、名前を付ける（例：base / blade）。名前がそのままステップと対応づく。
    2. glTF Binary（.glb）で書き出す — Blender 標準機能。1ファイルにモデルと質感が全部入る。
    3. このページのモデル生成部分を差し替える — プリミティブ生成を消し、GLTFLoader で model.glb を読み込む。ステップ定義（タイトル・解説・対象部品名）の配列はそのまま使う。
    4. フォルダごと GitHub Pages へ — index.html と model.glb を同じフォルダに置いて push するだけ。Three.js 本体は CDN 参照のままでよい。
    5. 題材を差し替える — 扇風機でなくても、PC自作・自転車の輪行・家具の組み立てなど、「部品＋手順」があるものなら同じ型で作れる。

    試作の割り切り：質感（PBRマテリアル）や影の細かさは Verge3D のデモより簡素です。ただし教材としての骨格——手順・ハイライト・読み上げ・タイムライン——は全部そろっています。
