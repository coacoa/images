Three.js Prototype

卓上扇風機の組み立てチュートリアル Verge3D の e-learning デモと同じ操作感を、無料の Three.js でどこまで再現できるかの試作

モデルは Blender ではなく Three.js の図形（プリミティブ）の組み合わせで作っていますが、ガードのワイヤーや羽根の形状、モーターの放熱スリットまで実物に寄せて作り直しました。見せ方もデモに近づけ、ステップごとにカメラが部品へ寄り、注釈コールアウトが部品を指します。本番ではここを Blender から書き出した glTF（.glb）に差し替えるだけで、ステップ解説・ハイライト・読み上げ・タイムラインはそのまま使えます。ビューアはフルスクリーン表示に対応し、解説パネルには全ステップを通して聞ける聞くモード（リスニング連続再生）も付けました。ページ下部には、この型を乗り物・交通ルール・PC組み立てなどへ展開するアイデアもまとめています。

      GitHub Pages で本番化する手順

      この試作を「自分のモデルの教材」に育てる流れ。

      1. Blender でモデルを作る — 部品ごとにオブジェクトを分け、名前を付ける（例：base / blade）。名前がそのままステップと対応づく。
      2. glTF Binary（.glb）で書き出す — Blender 標準機能。1ファイルにモデルと質感が全部入る。
      3. このページのモデル生成部分を差し替える — プリミティブ生成を消し、GLTFLoader で model.glb を読み込む。ステップ定義（タイトル・解説・対象部品名）の配列はそのまま使う。
      4. フォルダごと GitHub Pages へ — index.html と model.glb を同じフォルダに置いて push するだけ。Three.js 本体は CDN 参照のままでよい。
      5. 題材を差し替える — 扇風機でなくても、PC自作・自転車の輪行・家具の組み立てなど、「部品＋手順」があるものなら同じ型で作れる。

      試作の割り切り：モデルはまだプリミティブの組み合わせで、実物の曲面の滑らかさには届きません。ただし質感は ACES トーンマッピングと金属／樹脂マテリアルで実物寄りに寄せ、教材としての骨格——手順・注釈・カメラワーク・ハイライト・読み上げ・タイムライン——はデモと揃えてあります。

      この「型」で展開できる題材

      この試作のエンジン——ステップ定義（タイトル・解説・対象部品・確認ポイント）＋部品ハイライト＋カメラワーク＋読み上げ＋聞くモード＋タイムライン——は、モデルとステップ定義を差し替えるだけで使い回せます。「部品があって、手順があって、間違えると困るもの」が好相性です。

      車のメンテナンス 乗り物

      エンジンルームは部品が密集していて、写真や文章では「どれのことか」が伝わりにくい題材。3Dで対象部品だけ光らせれば一発で分かります。

      • タイヤ交換 — ジャッキのかけ位置、ホイールナットの対角締め順
      • バッテリー交換・ブースター接続 — プラス／マイナスの順序ミスが事故になる手順こそステップ化向き
      • エンジンオイル・冷却水の点検 — ゲージとリザーバータンクの場所探しが本体

      バイクのメンテナンス 乗り物

      チェーンやブレーキなど「調整の加減」が肝の部品が多く、分解⇔組立タイムラインで動きを見せられます。

      • チェーン清掃・注油・張り調整 — たるみ量の目安をモデル上で表示
      • ブレーキパッド交換 — キャリパーの外し方とピストン戻し
      • プラグ交換 — 締め付けトルクの感覚を手順で補う

      自転車の修理・整備 乗り物

      構造がシンプルでモデルの作りやすさも一番手頃。出先トラブル対応は「スマホで開いて、その場で見ながら直す」使われ方と相性がいい題材です。

      • パンク修理（チューブ交換） — タイヤレバーの使い方と噛み込み注意
      • ブレーキ・変速の調整 — ワイヤーの張りとリミットネジ
      • 輪行の組み立て — バラす逆順でそのまま教材になる

      交通ルールの啓蒙 啓蒙・教育

      組み立て型ではなく「場面再現型」への応用。視点を切り替えられるのが3Dの独壇場で、文章や標識クイズでは伝わらない「見え方そのもの」を体験させられます。

      • 死角体験 — トラックの運転席視点⇔自転車・歩行者視点を切り替え、内輪差と巻き込みを再現
      • 交差点の優先関係 — 車・バイク・自転車・歩行者を置いて「誰が止まるべきか」を場面ごとに確認
      • 自転車の通行ルール — 車道左側通行、二段階右折、歩道通行の条件をコース上で再現

      PCの組み立て 自作PC

      扇風機とまったく同じ「部品＋手順」の構造で、この型の本命候補。ケーブルの配線先は写真では必ず迷うので、行き先を光らせる価値が大きい題材です。

      • CPU・クーラー取り付け — 切り欠き合わせとグリスの塗り方
      • メモリ・M.2 SSD — スロットの優先順位とラッチの感覚
      • フロントパネル配線 — 小さいピンの行き先を1本ずつハイライト

      家電・日用品の手入れ 暮らし

      「年に数回しかやらないから毎回忘れる」作業は、手順教材の需要が安定しています。

      • エアコンのフィルター掃除 — カバーの開け方と爪の位置
      • 洗濯機の糸くずフィルター・排水口掃除
      • 換気扇・レンジフードの分解清掃 — 外す順序がそのまま教材

      作り方の優先順位のおすすめ：モデルが一番簡単なのは自転車とPC（直線・平面の部品が多い）。交通ルール啓蒙はモデルより「場面と視点切り替え」の設計が本体になります。どれも、このページのステップ定義の配列を書き換えるところから始められます。
