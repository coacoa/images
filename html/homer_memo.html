Homer Dashboard Configuration Memo

最終更新: 2026-08-21

1. 改修の概要

  • NixOS (Flakes) 上で Nginx + Homer によるローカルダッシュボードを構築。
  • 画面最上部のアナウンス領域（message）に NixOS の日常メンテナンス用コマンド（クリーンアップ／再構築）を配置。
  • 一時的に非表示にしたい項目は YAML のコメントアウト（#）で制御。

2. 設定時のハマりポイント・ノウハウ

  • YAMLのブロック構文（content: |）:
    content 内にダブルクォーテーションや HTML タグ（<code> 等）を直接書くと、Nix の多行文字列（''）や YAML 解析でクォートエラー（YAMLParseError）が発生する。多行テキストには | を使用する。
  • message の配置場所:
    Homer の仕様上、message ブロックは YAML ファイル内の記述順に関係なく、**常に画面最上部（ヘッダー直下）に強制配置**される。
  • リンクの無効化（コメントアウト）:
    サービス単位やアイテム単位で頭に # を付けて無効化する。

3. 登録済み NixOS コマンド (Cheatsheet)

# ガベージコレクション（1日以上前の世代を削除）
sudo nix-collect-garbage --delete-older-than 1d

# Nix Store の最適化（ハードリンク化）
nixos-rebuild switch --option store-optimise true

# Flake からのシステム再構築
sudo nixos-rebuild switch --flake .#hostname
