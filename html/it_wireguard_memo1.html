🔐 VPN / WireGuard を「感覚」で理解する

このHTMLは GitHubに置いて読み返す用メモ。 ボタンで ON / OFF しながら理解する。

① VPNって何をしてる？

一言でいうと：
「インターネット上に、見えない専用ケーブルを作る」

💻 あなた
➡️🔒➡️
🌍 Internet
➡️🔒➡️
🖥 VPN先

🔒 の部分が 暗号化トンネル
中身は外から見えない

② VPNが無いとき（普通の通信）

💻 あなた
➡️👀➡️
🌍 Internet
➡️👀➡️
🖥 サーバー

👀 = 経路は公開道路
HTTPSでも 行き先や構造は見える

③ WireGuard は何が違う？

VPNの一種だけど、考え方がシンプル。

  • 🔑 ID/PW なし
  • 🧾 「公開鍵を持ってるか」だけ
  • 📦 OSレベルで超軽量
💻 Client
鍵A
🔐
🖥 Server
鍵B

✔ 鍵が合えば即通信
❌ 合わなければ存在すら見えない

④ WireGuard = 仮想LAN

PC
10.0.0.2
──
WG
──
Server
10.0.0.1

インターネット越しなのに
同じLANにいる扱い

⑤ なぜ「AllowedIPs」が重要？

❌ 危険：

AllowedIPs = 0.0.0.0/0

→ 全通信がVPNに吸われる
→ LANも全部丸見え

⭕ 安全：

AllowedIPs = 10.0.0.1/32

→ 必要な相手だけ

⑥ Tailscale との違い（感覚）

  • Tailscale = 鍵管理と道案内を代行
  • WireGuard生 = 鍵も道も自分管理
