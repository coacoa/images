Obsidian Vim キーバインド完全一覧

Obsidianの標準Vimモード（簡易Vimエディタ）で使える主要なコマンド・ショートカットの完全版

1. モードの切り替え

操作説明
ESCコマンドモード（ノーマルモード）へ移行
iカートルの位置からインサートモードへ移行
I行頭に移動してインサートモードへ移行
aカーソルの右隣からインサートモードへ移行
A行末に移動してインサートモードへ移行
o下行に新しい行を開いてインサートモードへ移行
O上行に新しい行を開いてインサートモードへ移行

2. カーソル移動（モーション）

操作説明
h / j / k / l左 / 下 / 上 / 右へ移動
w次の単語の先頭へ移動
b前の単語の先頭へ移動
e単語の末尾へ移動
0 / ^行頭へ移動
$行末へ移動
ggファイルの先頭へ移動
Gファイルの末尾へ移動
数字 + G指定した行番号へ移動（例: 15G）
%対応する括弧（() や {}）へジャンプ

3. 編集・削除・変更

操作説明
xカーソル上の文字を削除
dd行全体を削除（カット）
dw1単語を削除
Dカーソルから行末までを削除
cc行全体を削除してインサートモードへ
cw単語を変更（削除してインサートモードへ）
r指定した1文字に置換
~大文字・小文字を反転
u元に戻す（アンドゥ）
Ctrl + r または .やり直す（リドゥ） / 直前の操作を繰り返し

4. コピー（ヤンク）・ペースト・ビジュアルモード

操作説明
v文字単位のビジュアルモード（選択開始）
V行単位のビジュアルモード（行選択）
Ctrl + v矩形選択モード
y選択範囲をコピー（ヤンク）
yy行全体をコピー
pカーソルの後ろに貼り付け（プット）
Pカーソルの前に貼り付け

5. 検索・置換

操作説明
/前方検索
?後方検索
n / N次の検索結果へ / 前の検索結果へ
*カーソル上の単語を前方一致で検索
:%s/旧/新/gファイル内の文字列を一括置換

6. テキストオブジェクト（応用）

動詞（d, c, y）と組み合わせることで、記号の内側などを効率よく操作できます。

操作説明
di( または di)括弧 () の内側を削除
da( または da)括弧 () ごとすべて削除
di{ / da{波括弧 {} の内側 / 全体を削除
di" / da"ダブルクォーテーション "" の内側 / 全体を削除
ci`バックティック `` の内側を変更（Markdownのインラインコード編集に便利）
