Obsidian 使い方マニュアル

Obsidian は、ローカルで動作する Markdown ベースのノートアプリです。双方向リンクでノートを繋ぎ、知識ネットワークを構築できます。

1. Obsidian とは

Obsidian は、以下の特徴を持つノートアプリです：

  • ローカル保存：データはすべてあなたの PC 上に保存されます
  • Markdown 形式：標準的なテキスト形式で、将来も読みやすい
  • 双方向リンク：ノート同士をリンクで繋ぎ、ネットワークを構築
  • グラフビュー：ノートのつながりを視覚的に確認可能
  • 無料・高機能：個人利用は完全無料、650 以上のプラグインで拡張可能

2. 基本の使い方

2.1 保管庫（Vault）の作成

  1. Obsidian を起動
  2. 「Create new vault」を選択
  3. 保存場所と名前を指定
  4. 「Create」をクリック

2.2 ノートの作成

  • 新規ノート：Ctrl + N（Mac: Cmd + N）
  • ファイル名をつけて保存（.md 形式）
  • Markdown で記述（見出し、リスト、リンクなど）

2.3 リンクの作成

  • 内部リンク：[[ノート名]]
  • 埋め込み：![[ノート名]]
  • リンク挿入：Ctrl + K（Mac: Cmd + K）

2.4 検索

  • 現在のノート内検索：Ctrl + F（Mac: Cmd + F）
  • Vault 全体検索：Ctrl + Shift + F（Mac: Cmd + Shift + F）
  • クイックスイッチャー：Ctrl + O（Mac: Cmd + O）

4. 便利な機能

4.1 コマンドパレット（Ctrl + P / Cmd + P）

すべてのコマンドを検索して実行できます。ショートカットがわからない機能もここから探せます。

4.2 グラフビュー（Ctrl + G / Cmd + G）

ノート同士のつながりを視覚的に表示。思考のネットワークを把握できます。

4.3 クイックスイッチャー（Ctrl + O / Cmd + O）

ファイル名を入力して瞬時にノートを開けます。頻繁にノートを移動する際に便利です。

4.4 テンプレート

よく使うノート形式をテンプレート化：

  1. テンプレートフォルダを作成
  2. コアプラグイン「テンプレート」を有効化
  3. テンプレート挿入：Ctrl + Shift + I（Mac: Cmd + Shift + I）

4.5 検索と置換

  • 現在のノート内検索：Ctrl + F
  • 置換：Ctrl + H
  • Vault 全体検索：Ctrl + Shift + F

5. プラグイン活用

5.1 コアプラグイン

  • テンプレート：定型文を素早く挿入
  • デイリーノート：日付ベースの自動ノート作成
  • タグペイン：タグの一覧表示
  • アウトライン：見出し構造を表示
  • バックリンク：他のノートからの参照を表示

5.2 コミュニティプラグイン

設定 → コミュニティプラグイン → 「閲覧」でインストール可能：

  • Dataview：データベースのようにノートをクエリ
  • Calendar：カレンダー表示でデイリーノート管理
  • Advanced Tables：表編集を効率化
  • Obsidian Git：Git で自動バックアップ
  • QuickAdd：カスタムアクションを作成

6. 始め方のヒント

  1. まずは小さく：1 つのプロジェクトやテーマから始める
  2. リンクを習慣化：関連するノートは積極的にリンク
  3. タグは控えめに：フォルダとリンクで整理、タグは補助的に
  4. 毎日のノート：デイリーノートで思考を記録
  5. 週次レビュー：グラフビューでつながりを確認
