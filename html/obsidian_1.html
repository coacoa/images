Obsidian Vim ＆ 独自ショートカット完全一覧

Vimモードの基本操作に加え、リンク移動・ノーマルモードからの独自機能拡張を完全網羅

1. Obsidian特有のVim操作（リンク・見出し・履歴）

ノーマルモード時、ObsidianのVim設定（Use Vim key bindings）によって有効になる独自のキーマッピングです。
操作説明
gdカーソル下の**内部リンクにジャンプ**（ファイルを開く）
[[前の見出し（Heading）へジャンプ
]]次の見出し（Heading）へジャンプ
Ctrl + oジャンプ履歴を**戻る**（ブラウザの「戻る」に相当）
Ctrl + iジャンプ履歴を**進む**

2. モードの切り替え

操作説明
ESC または Ctrl + cコマンドモード（ノーマルモード）へ移行
iカーソルの位置からインサートモードへ移行
I行頭に移動してインサートモードへ移行
aカーソルの右隣からインサートモードへ移行
A行末に移動してインサートモードへ移行
o下行に新しい行を開いてインサートモードへ移行
O上行に新しい行を開いてインサートモードへ移行

3. カーソル移動（モーション）

操作説明
h / j / k / l左 / 下 / 上 / 右へ移動
w / b / e次の単語の先頭 / 前の単語の先頭 / 単語の末尾へ移動
0 / ^ / $行頭（絶対） / 行頭（最初の文字） / 行末へ移動
gg / Gファイルの先頭 / 末尾へ移動
数字 + G指定した行番号へ移動（例: 15G）
%対応する括弧（() や {}）へジャンプ

4. 編集・削除・変更

操作説明
xカーソル上の文字を削除
dd / dw / D行全体を削除 / 1単語削除 / カーソルから行末まで削除
cc / cw行全体を変更（削除して入力） / 単語を変更して入力
r指定した1文字に置換
~大文字・小文字を反転
u / Ctrl + r元に戻す（アンドゥ） / やり直す（リドゥ）
.直前の操作を繰り返す

5. コピー・ペースト・ビジュアルモード

操作説明
v / V / Ctrl + v文字単位 / 行単位 / 矩形選択のビジュアルモード
y / yy選択範囲をコピー（ヤンク） / 行全体をコピー
p / Pカーソルの後ろ / 前に貼り付け（プット）

6. 検索・置換

操作説明
/ / ?前方検索 / 後方検索
n / N次の検索結果 / 前の検索結果へ移動
*カーソル上の単語を前方一致で検索
:%s/旧/新/gファイル内の文字列を一括置換

7. ノーマルモードから役立つObsidian標準ショートカット

Vimモード有効時でも、一部のグローバルショートカットやコマンドパレットを併用することでObsidianの操作性が飛躍的に向上します。
操作 (Obsidian標準)説明
Ctrl + p**コマンドパレットを開く**（あらゆる機能・プラグインを文字入力で実行）
Ctrl + o**クイックスイッチャー**（ファイル名検索して素早く切り替え）
Ctrl + Shift + fファイル全体（ヴォールト内）を横断検索
Ctrl + Shift + iリンクを挿入（[[]] の補完メニューを呼び出し）
Ctrl + Enterチェックボックスのオン/オフを切り替え
