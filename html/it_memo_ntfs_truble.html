🛠️ NTFS Mount Fix for NixOS

症状: 外付けHDDが見えない、マウントできない、Read-onlyになる。

1. Dirtyフラグを強制解除する

ツールがない場合はnix-shell経由で実行：

nix-shell -p ntfs3g --run "sudo ntfsfix -d /dev/sdc1"

2. 強制的にマウントする

sudo mkdir -p /mnt/external
sudo mount -t ntfs-3g /dev/sdc1 /mnt/external

3. 状態を確認する

sudo dmesg | tail -n 20
lsblk

💡 根本解決：ext4へのフォーマット

（※中身が全部消えるので注意）

# パーティションをext4で初期化
sudo mkfs.ext4 /dev/sdc1
