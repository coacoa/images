Controller Setup Guide / コントローラー最適化設定メモ

Target: GT7-like handling response with Right-Stick Throttle (右スティックアクセル仕様)

📍 Menu Path / 設定画面へのアクセス
Options > Controls > Configuration / Advanced
⚙️ Recommended Controller Settings / 推奨設定一覧
Setting Item (English / 日本語) Value (設定値) Description & Role (役割と理由)

🔧 Fine-Tuning Guide / フィーリング微調整
  • If turning feels understeer / 曲がり足りないと感じる場合:
    Decrease Speed Sensitivity (e.g. 80 → 70) or slightly increase Steering Sensitivity (e.g. 5 → 15).
  • If the car feels nervous or spins easily / カクついてスピンしやすい場合:
    Set Steering Sensitivity to 0 and increase Speed Sensitivity up to 85.
🎮 Right Stick Throttle Tips / 右スティックアクセル（縦入力）のコツ

When using Right Stick UP (Throttle) / DOWN (Brake):
Keep deadzones at 0 and sensitivities low (0–20). This mimics GT7's analog trigger/stick precision, allowing fine modulation without accidental diagonal inputs.

右スティック（上：アクセル / 下：ブレーキ）操作では、デッドゾーンを0、感度を0〜20の低めに設定することで、GT7のような繊細なアクセル開度調整が可能になります。
