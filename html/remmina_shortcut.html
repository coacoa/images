Remmina 標準ショートカットキー一覧

※「ホストキー」はデフォルトでは 右 Ctrl キー です。
多くのショートカットは「ホストキー + 文字キー」で動作します。 バージョンやディストリによって異なる場合があるので、 設定 → キーボード で確認・変更できます。

キー 機能
右 Ctrl キーボード取得のオン/オフ切り替え（Grab all keyboard events）
ホストキー + F フルスクリーン切り替え（fullscreen）
ホストキー + A ウィンドウサイズに自動フィット（autofit）
ホストキー + PageUp 前のタブへ移動（prevtab）
ホストキー + PageDown 次のタブへ移動（nexttab）
ホストキー + +/- スケール変更（scale）
ホストキー + G キーボード取得のオン/オフ（grab）
ホストキー + M ウィンドウを最小化（minimize）
ホストキー + V ビューのみモード切り替え（viewonly）
ホストキー + S スクリーンショット取得（screenshot）
ホストキー + D 接続を切断（disconnect）
ホストキー + T ツールバー表示/非表示切り替え（toolbar）

実際のキー割り当ては環境によって違うことがあるので、 Remmina の「設定 → キーボード」で確認しておくと安心です。
