🎬 アニメでわかる git pull --rebase

🙂

第1話：平和な日常

main にいる。
「よし、git pull --rebase するか〜」

🤖

第2話：Git の作業開始

Git「OK！
じゃあ 君の commit を1個ずつ
新しい main の上に乗せ直すね」

💥

第3話：衝突（conflict）発生！

Git「この commit a、
ぶつかった！どうする？」

👉 状態：rebase 中（時間停止）

😵

第4話：やってはいけない行動

git pull
git restore .

Git「ちょっと待って！！
まだ話の途中！！！」

🧠

第5話：真実に気づく

「あ、この commit いらんやつだ」

👉 正解コマンド： git rebase --skip

✨

最終話：世界は救われた

Successfully rebased and updated refs/heads/main
On branch main
working tree clean

🎉 完全に正常

📺 1画面まとめ（超重要）

git pull --rebase ↓ conflict 発生 ↓ 【選択肢】 ・直す → add → rebase --continue ・いらない → rebase --skip ← 今回 ・全部やめる → rebase --abort ↓ rebase 完了

🧭 覚えるセリフ（アニメ的）

  • Git「今 rebase 中？」→ git status
  • Git「話を進めて」→ --continue
  • Git「この話いらん」→ --skip
  • Git「最初からやり直す」→ --abort
