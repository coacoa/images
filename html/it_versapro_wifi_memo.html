📟 VersaPro Wi-Fi 基地局 備忘録

重要 VersaProのWi-Fiチップ (wlp2s0) でAPを立てる際の正解コマンド：

sudo create_ap -n wlp2s0 KADEN_TRANSCEIVER password123
  • -n : インターネット共有を行わない（独立した基地局モード）
  • wlp2s0 : インターフェース名（VersaProの標準）

🛠 トラブルシューティング

Wi-Fiが見つからない、またはエラーが出た時のリセット手順：

# 1. 既存プロセスを掃除
sudo killall -9 create_ap hostapd dnsmasq

# 2. NetworkManagerの干渉を防ぐ
sudo nmcli device set wlp2s0 managed no

# 3. Wi-Fiのロック解除
sudo rfkill unblock wifi

📱 トランシーバーUI (HTML/JS) の肝

マイク録音をWebM形式でPCサーバーに飛ばすJavaScriptのコア部分：

// 録音停止時に自動でPOST送信するロジック
mediaRecorder.onstop = async () => {
  const blob = new Blob(chunks, { type: 'audio/webm' });
  const fd = new FormData();
  fd.append('audio', blob);
  fetch('/talk', { method: 'POST', body: fd });
  chunks = [];
};

※ NixOS configuration: /etc/nixos/network.nix にて永続化済み
