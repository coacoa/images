OpenWrt (ac16) mDNS導入 & AdGuard Home ポート調整メモ

環境情報
  • OS: OpenWrt 23.05.6
  • ホスト名: ac16（変更済み）
  • ネットワーク構成:
    • WAN/上流側: 192.168.1.1/24
    • LAN/Wi-Fi側: 192.168.230.1/24 (NAT構成)

1. ポート割り当て構成図

5353/UDP ポートにおける AdGuard Home と umdns の競合を回避するため、以下の配置に整理。

サービス ポート 役割・接続フロー
dnsmasq 53 LAN端末からのDNS問い合わせを受信 ➔ 127.0.0.1#5553 へ転送
AdGuard Home (DNS) 5553 広告ブロック処理を実施 ➔ 外部DNS (1.1.1.1等) へ上流問い合わせ
umdns (mDNS) 5353 ac16.local の名前解決に対応 (mDNS標準規格のため変更不可)
AdGuard Home (WebUI) 8080 管理画面アクセス用 (http://ac16.local:8080)

2. 実施手順ログ

Step 1. ホスト名を `ac16` に変更

/etc/config/system を書き換えて固定。

vi /etc/config/system

# 以下の行を変更
config system
        option hostname 'ac16'

# 反映
hostname ac16
/etc/init.d/system reload

Step 2. `umdns` (mDNS) のインストール

opkg update
opkg install umdns
/etc/init.d/umdns enable
/etc/init.d/umdns start

Step 3. AdGuard Home の DNS ポート変更 (`5553`)

設定ファイルの dns.port を 5553 に変更して衝突回避。

vi /etc/adguardhome.yaml

# 変更箇所
dns:
  bind_hosts:
    - 0.0.0.0
  port: 5553

Step 4. dnsmasq の転送先指定 & DHCPオプション確認

dnsmasq から AdGuard Home (5553) へフォワードを設定。

# 上流を 127.0.0.1#5553 に指定
uci del dhcp.@dnsmasq[0].server 2>/dev/null
uci add_list dhcp.@dnsmasq[0].server='127.0.0.1#5553'
uci set dhcp.@dnsmasq[0].noresolv='1'

# LAN側端末に配るDNSサーバーを自身(192.168.230.1)に固定
uci del dhcp.lan.dhcp_option 2>/dev/null
uci add_list dhcp.lan.dhcp_option='6,192.168.230.1'

uci commit dhcp
/etc/init.d/dnsmasq restart

Step 5. サービスの全再起動

/etc/init.d/adguardhome restart
/etc/init.d/dnsmasq restart
/etc/init.d/umdns restart

3. 状態確認用コマンド（トラブルシューティング）

ポート確認:

netstat -tulpn | grep -E ":53|:5553"

AdGuard Home の設定エラーチェック:

/usr/bin/AdGuardHome --config /etc/adguardhome.yaml --check-config

DNS応答テスト:

nslookup google.com 127.0.0.1#5553
接続確認用URL:
・OpenWrt 管理画面: http://ac16.local
・AdGuard Home 管理画面: http://ac16.local:8080
