Podman の policy.json を heredoc（EOF）で作るメモ

Podman（特に NixOS）では、イメージの信頼ポリシーを policy.json で明示しないと podman build / podman pull が失敗することがある。

目的

  • Docker と同じ感覚でローカル開発を進めたい
  • 毎回エラーにハマらないよう、設定を覚えやすく可視化

やること（結論）

~/.config/containers/policy.json を作成し、
すべてのイメージを許可する設定を入れる。

コマンド（heredoc / EOF）

mkdir -p ~/.config/containers
cat <<'EOF' > ~/.config/containers/policy.json
{
  "default": [
    {
      "type": "insecureAcceptAnything"
    }
  ]
}
EOF

ポイント

  • <<'EOF' → シングルクォート付きで変数展開を防止
  • ユーザー単位なので sudo 不要

この設定の意味

"type": "insecureAcceptAnything" は：

  • 署名検証をしない
  • すべてのコンテナイメージを信用する

＝ Docker と同じ挙動（ローカル用途向け）

確認

podman build -t add_subtitles_comp .

補足（本番環境では）

  • 本番や公開サーバでは署名付きイメージを使う
  • insecureAcceptAnything は避ける
