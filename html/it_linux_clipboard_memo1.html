🧠 Linux Clipboard 学習メモ

[1] 入力デバイス
[2] ウィンドウシステム (X11 / Wayland)
[3] Clipboard Provider (xclip / wl-clipboard)
[4] アプリ (vim / nvim / browser)

Linux のコピペは 1つの仕組みではなく、レイヤー構造。

  • Ctrl+C / Ctrl+V を押すだけ
  • コピーの意味は理解していない
  • ただのキーイベント

X11 の clipboard は複数ある

  • PRIMARY：選択しただけ
  • CLIPBOARD：Ctrl+C / Ctrl+V

X11 / Wayland は 箱を用意するだけ。 中身は知らない。

  • X11：xclip, xsel
  • Wayland：wl-clipboard

Provider は アプリと clipboard の橋。 

vim → xclip → X11 clipboard → browser
  • GUI アプリ：最初から clipboard 対応
  • vim / nvim：provider が必須

vim では unnamedplus が重要。 

set clipboard=unnamedplus
vim.opt.clipboard = "unnamedplus"

Linux の clipboard は 共有メモリではなくストリーム。

  • アプリ終了で消えることがある
  • provider が無いと繋がらない
  • 環境（X11 / Wayland）依存
